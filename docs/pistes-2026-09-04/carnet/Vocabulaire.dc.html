Le carnet — les mots

Comment on appelle les choses

Un mot pour une chose, et le même partout : à l'écran, dans les menus, dans le guide, et dans ce qu'on écrit à propos de l'atelier. Ce qui n'est pas dans cette page ne s'écrit pas.

Comment ça s'emboîte

Cinq niveaux, du plus grand au plus petit. Un seul est libre : les collections, qu'on crée soi-même. Les autres sont posés par l'atelier.

Ce que chaque famille apporte

C'est la famille qui décide de ce qu'un sujet possède et des outils qu'on trouve sur sa page. Un personnage et un terrain n'ouvrent pas le même écran.

Quatre règles

Un mot, une chose
Jamais deux mots pour la même chose, jamais le même mot pour deux. Si un écran a besoin d'un mot qui n'est pas ici, c'est cette page qu'on modifie d'abord.
On dit la famille quand on peut
« Ajouter un personnage », pas « ajouter un sujet ». Le mot sujet ne sort que lorsqu'on mélange les familles : une recherche, un compte total, une définition.
Les familles restent au pluriel
Dans le carnet et dans les menus, on écrit « Les personnages », « Les terrains ». Au singulier, on parle d'un sujet précis.
Ce qui ne s'affiche pas ne se définit pas
Cette page ne liste que les mots qu'un utilisateur voit. Ce qui n'existe que dans le code n'a pas à porter un nom pour lui.
