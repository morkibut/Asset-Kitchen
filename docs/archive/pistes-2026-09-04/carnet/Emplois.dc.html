Trois mots à ne pas confondre ce que dit le carnet, ce que dit le code
un emploi le carnet
une pièce le code
Le carnet appelle « emploi » chaque façon dont un objet sert : l'épée en main, l'épée au sol, l'épée en icône. Le code n'a pas ce mot dans ce sens — il l'emploie ailleurs, pour le compteur d'usages d'une étiquette. C'est une proposition du carnet, pas un relevé.
un emplacement le carnet
un emplacement le code
Les deux disent la même chose : un endroit du corps. Six sont proposés, jamais imposés, et dans l'ordre où ils s'empilent : le dos, le corps, les jambes, le torse, les mains, la tête. Un emplacement ne place rien : c'est un nom et un rang.
jusqu'où elle va le carnet
sa portée le code
Deux valeurs, et pas une de plus : contenue, qui tient dans la silhouette du corps, et agrandit, qui déborde. C'est l'auteur qui le déclare ; rien ne le devine du nom de la pièce. Le choix change la place laissée autour du corps sur la planche envoyée : 92 % ou 62 %.
